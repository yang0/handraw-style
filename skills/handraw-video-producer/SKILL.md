# 🎬 Handraw & Knowledge Video Hub · 视频制作总控中枢

协调工作区视频的设计、配音、素材、渲染与版本修订。先确定题材、实际素材与可实现的运动层级，再选择模式；分层角色表演、插画微运镜和真实录屏用途不同，不把它们都描述成完整动画。用户的画幅、配音服务、素材和已确认方向优先于模板示例。

新制作先确定画幅、受众、内容边界及全片视觉/运动方向。读取当前风格/图型/色库权威记录后选择，不把示例主题、编号、固定幕数、音色、图集格数或尾卡时长设为通用要求。风格注册不等于现成贴纸；交付时区分已生成、已接入、已验证与待审。

叙事长卷按“主题与事件 → 角色和场景共同设计 → 动作与反馈 → 素材 → 合成”推进。每个叙事段落写清角色意图、行动、场景变化与角色反应，再选择能承载互动的场景和素材；氛围片仍可选择纯景观。具体设计、表现层级及验收见[长卷手册](references/unbounded_scroll_director_guide.md)，角色与场景的空间适配见[素材契约](references/frame_and_asset_contract.md)。

用户指定画卷讲知识、科普、历史或过程时，保留`scroll`模式，读取[知识长卷指南](references/scroll_knowledge_guide.md)。以学习目标和事实组织连续世界，通过过程、关系、对比或尺度变化解释知识；角色可选，同一画风可以贯穿。先设计知识与可见证据，再安排口播锚点、解释图层和镜头，不自动改成A/B-roll、不强制跨画风。知识长卷是制作分支，解释图层与事件时间线须核对实际实现，不是新增CLI模式。

综合艺术动画已迁入本包的`lib/art_motion/`，覆盖参考拆解、艺术场景、口播画面、长卷、九类解说、角色/图集、配乐和QA。制作艺术动画、知识解释片段或参考复刻时读取[综合艺术动画集成指南](references/art_motion_integration_guide.md)，再按任务加载相应方法卡。先选解释语法，再绑定当前手绘外观与布局；使用`hvp art-motion`入口，原五种模态及期内脚本仍按原协议运行。画风ID解析与素材提示不等于程序化渲染器已实现该画风，精确文字与知识关系使用可编辑层。

字幕按用途选择，不是固定加层。区分画面标题/步骤/标签、同步解说字幕和内部语音时间线；图文已覆盖核心信息时可不叠加重复旁白，口播、静音理解或无障碍需求仍可保留字幕。“不要字幕”不等于删掉所有画面文字或取消配音。新制作选模式并说明理由，旧工程不因新增偏好自动改版，详细策略见下述字幕手册。

## 二、 核心导演规范与参考手册

各个模态均有独立的专业导演手册供详细查阅与严格遵循：

只加载当前模式所需的手册；已有作品的局部修改沿用原模式、素材与制作链路，不重新启动选题。仅改画面时不重做配音；用户要求修改配音时重新合成并检查字幕、镜头锚点和混音依赖。

1. **动态漫导演手册（v1.2）**：[`references/motion_comic_director_guide.md`](references/motion_comic_director_guide.md)
   - 3×2 Sprite Atlas 姿态图集规约（Cell 0~2 基础/深入/呆滞姿态，Cell 3 反转姿态，Cell 4~5 独立道具）；
   - 分层舞台背景规约（示例为9:16，实际按用户画幅）；另支持已确认的多关键画面有限动态漫；
   - 物理弹簧气泡（`0.86 压缩 -> 1.06 冲顶 -> 1.00 稳定`）；
   - 喜剧反转可从0.6–0.8秒冻结与留白试起，不套用于所有题材。
   - 气泡指向不等于尖角必须触及声源；按镜头变换与弹入峰值避让头脸、关键道具；
   - 特效按叙事选择并跟随角色锚点，验证出现、运动、保持与退场；多场景不能替代漫画表演，局部修订保留未要求改变的表现。
2. **知识双轨教程导演手册（v2.5 · LiveCanvas、少帧整图表演与互动）**：[`references/knowledge_abroll_director_guide.md`](references/knowledge_abroll_director_guide.md)
   - ⚪ A-roll 按语义选择：不分离角色/场景的两三张完整图按顺序与延时硬切、分层定格姿态切换、空镜角色/道具分层登场、局部简单循环；整图与分层路线分别记录，效果演示按已选类型核对覆盖，不用全身浮动或分层换姿势冒充整图定格；
   - 整图定格可承载动作、姿势、表情、角色与环境/道具或其他角色的互动；少帧不等于微小变化，按情绪与因果设计可读的关键状态。身份保持不等于表情冻结，互动要有接触及反馈，详见手册；
   - 简单局部循环优先两帧，有需要再加第三帧；只动一个局部的限制不套用于整图表演。嘴边扩散线优先直接绘制，随实际说话启停，属于说话示意而非口型同步；
   - 分镜记录素材、帧顺序/停留、动作区间和结果保持；模板现有姿态选择不等于循环/语音门控已实现，制作时核对链路并动态验收，详见手册；
   - ⚫ B-roll 黑底知识增量：实操录屏、信息图型（步骤流/对比卡）、**LiveCanvas 实况动态数据看板**（Versus 对决柱形、Trend 趋势折线划出、Hero 英雄大指标）；
   - **反假大空铁律**：标题与结论直接写主体+确切数字+明确结论，对比必注评测机构、口径与基准日期；
   - 以信息节点组织双轨轮替，10–15秒为可调整的起点，不承诺完播率。
3. **绘本导演手册（v1.2）**：[`references/watercolor_picturebook_director_guide.md`](references/watercolor_picturebook_director_guide.md)
   - `story` / `watercolor` / `picturebook` 新制作、切页或节奏修改时必读；
   - 单次图像衔接，开场显现与页间转场分离；舒缓绘本可从2秒叠化起步，用户指定优先；
   - 固定总时长内调整转场，复用音轨、保留旧版，并检查切点与成片。
4. **跨模式声画与修订指南**：[`references/audio_transition_revision_guide.md`](references/audio_transition_revision_guide.md)
   - 指定配音、演播改进、字幕重新对齐、镜头生硬或版本修订时读取；
   - 核验服务与参数实际生效，同图运镜与换景转场分开处理；
   - 配音实长驱动时间线，证据、试听与用户验收分开记录。
5. **插画白板导演手册（v1.2）**：[`references/sketch_whiteboard_director_guide.md`](references/sketch_whiteboard_director_guide.md)
   - whiteboard / sketch新制作或素材、排版、动效反馈时必读；
   - 实际插画、逻辑图表与文字页分工；先视觉/运动方向，再逐幕设计；不从逗号猜步骤或静默丢段落。
6. **画幅与素材契约**：[`references/frame_and_asset_contract.md`](references/frame_and_asset_contract.md)
   - 新制作、横竖屏转换、多画幅交付时必读；
   - 画布→CSS→viewport→编码尺寸一致；横竖重新分栏/分行与字幕安全区；明确图像/图集采样、实际语音段映射及检查矩阵。
7. **图文、配音与字幕分工**：[`references/subtitle_and_information_guide.md`](references/subtitle_and_information_guide.md)
   - 新制作选择字幕策略、信息过载反馈或去字幕时读取；
   - 画内字幕、仅SRT、无字幕三种策略；图文与内部时间线独立保留；
   - 去字幕仅改相关显示层，复用声音，另存新版并检查当前交付链接。
8. **艺术与知识长卷导演手册（v1.3）**：[`references/unbounded_scroll_director_guide.md`](references/unbounded_scroll_director_guide.md)
   - scroll / wander新制作、角色场景互动、延长时长、多图背景或长卷拼缝反馈时必读；
   - 主题与事件先行，角色与场景共同设计；互动分镜记录准备、执行、接触、结果及镜头安排；
   - 按素材契约对齐画风、比例、透视、光照与接触锚点，跨画风保持身份和动作连续；
   - 示范多图长卷时至少接入两张独立背景，不能把同图裁成两张算作多图示范；
   - 以实际配音和内容变化分配镜头；长视频增加段落、画卷与运动层次，不能只减慢一张图；
   - 羽化不能保证空间连续；检查接触、反馈、遮挡、过渡帧与结果可读性，背景横移帧差不能证明互动成立；
   - 区分静态姿态、动作关键帧与连续动画；缺失素材/实现单列，不因规范新增就宣称已支持或已验收。
9. **知识长卷制作指南（v1.0）**：[`references/scroll_knowledge_guide.md`](references/scroll_knowledge_guide.md)
   - 用画卷讲知识时与长卷手册同读；学习目标 → 事实与解释链 → 世界布局 → 口播锚点/过程事件 → 素材与合成；
   - 按时间、空间、因果或尺度组织画卷，角色与跨画风可选；一屏一个解释焦点，过程完成后留出阅读时间；
   - 记录事实来源、可见证据、解释图层、字幕分工及实现状态；示意路径、比例和时间压缩明确标注；
   - 提供水循环知识分镜范例与验收标准；目前为规范扩展，未新增通用解释图层接口或知识长卷成片验证。
10. **综合艺术动画与手绘适配（v1.0）**：[`references/art_motion_integration_guide.md`](references/art_motion_integration_guide.md)
    - 全路线方法、35个程序化场景、九类解说语法、片段/长卷/口播工程、角色工具与配乐；
    - 当前风格ID及旧编号、图型和颜色先由权威库解析；真实素材、分层换帧与显式CSS调色通过适配层接入；
    - 迁移清单、许可、示范角色替换与真实验证分开记录；上游历史结果不作为本项目验收证据。

### 已有视频的局部修订

先检查当前预览实际指向的成片、期内制作脚本和配置，不凭通用模板推断效果。限定改动及其必要依赖：换配音需要重新检查字幕、镜头和混音，通常不需要重新生图；只改转场则复用音轨并保留字幕时间线。“转场2秒”指整个衔接过程共2秒，不是退出2秒再入场2秒。期内已有版本化脚本时优先用它，避免全量 `build` 覆盖原片。

修订前列出“本次改动 / 必要依赖 / 保留项”：修气泡不弱化漫画特效，加场景不默认删掉角色表演，补特效不重新配音或改节奏。若依赖冲突确实需要改变已选表现，说明原因并取得必要确认。气泡遮脸、特效不明显等反馈先区分删除、未触发、被遮挡、锚点失配或可见时段不足，再针对原因修改；检查方法见动态漫手册与跨模式修订指南。

只去解说字幕时，保留标题、图内文字、图像位置、动效、配音和时长；关闭显示而不是删除内部语音边界。确认字幕实际所在层，并优先复用原片音轨；无干净源文件时不能承诺无损擦掉烧录文字。不要顺手重新排版或重做生成素材。

将新版写入 `outputs/revision_vN/` 或等价版本路径，并保留源配置。完成转场抽检、帧数/时长及全片解码后，再更新 `episode.json` 与 `preview.html` 的指向。技术检查通过不等于用户审美验收；没有用户确认时保持待审状态。详细绘本检查见上述手册。

## 三、 CLI 命令行工具 (hvp)

在项目根目录下，使用统一 CLI 工具进行全流程制作：

**能力边界**：通用 `tts` 当前默认使用 `lib/tts_engine.py` 的Edge-TTS；存在期内 `produce.py` 时才委托该脚本。配置其他服务名或演播指令不代表CLI支持它们；先检查实际实现，使用对应可用配音技能或期内适配器。`render` 在缺少时间线时可能隐式调用TTS；仅改画面前先核对缓存和委托逻辑。版本脚本并非通用CLI参数，不把单期适配说成全局升级。

`new`支持`--aspect 16:9` / `--aspect 9:16`，也可成对给`--width`、`--height`与`--fps`。默认白板通过storyboard.json实现hero/steps/compare/diagram，按画幅重排并拒绝缺图、漏段；旧sketch_template保留为旧版素材，不再作为新白板的默认。其他模态的旧模板尚含固定画布，横屏任务需要期内适配，渲染器会拒绝画布/输出不一致，不宣称仅设尺寸就已完成横屏。

默认whiteboard/sketch支持`--subtitle-mode burn-in|sidecar|none`：画内字幕、仅交付SRT、无字幕。省略沿用burn-in以兼容旧流程；新制作根据内容与需求显式选择。通用其他模态尚未接入none/sidecar，专属脚本需核对真实支持，不能只写配置字段宣称已关闭。

```bash
# 1. 新建一期工程 (支持 comic / knowledge / story / whiteboard / scroll)
python skills/handraw-video-producer/bin/hvp.py new "找手机找了个寂寞" --mode comic
python skills/handraw-video-producer/bin/hvp.py new "AI视频全自动出片教学" --mode knowledge
python skills/handraw-video-producer/bin/hvp.py new "横屏知识主题" --mode whiteboard --aspect 16:9
python skills/handraw-video-producer/bin/hvp.py new "竖屏知识主题" --mode whiteboard --aspect 9:16
```

## 四、 目录规约与交付标准 (Directory & Deliverables)

每期工程存放于 `videos/episodes/<YYYY-MM-DD 标题>/`：

新白板工程是草稿；填写剧本、选择风格/色值、准备实际图片与storyboard.json后再build。统一交付前检查素材/字体加载、每幕实际讲话帧、切点及回跳一致性、全片解码/帧数/实际音画时长/编码后响度。burn-in检查字幕边界与遮挡，sidecar检查实际时间与交付文件，none检查无解说字幕且图文信息保留、播放器不引用旧字幕。静帧与ASR不代替实际动态观看和听审。横竖双版本各自检查，通常复用音轨与素材，分别重排，不覆盖原版。

```text
videos/episodes/2026-10-08 找手机找了个寂寞/
├── episode.json         # 本期元数据 (模式、画幅、画风编号、主题色、声学配置)
├── script.txt           # 对白/旁白脚本 (分行或 "|" 切分)
├── design.md            # 导演设计案 (叙事拆解、逐镜动作表、笑点或转场规划)
├── storyboard.json      # 默认插画白板的显式分镜与素材映射，其他模态按需
├── assets/              # 本期素材 (background/sprites 或 ip/broll)
├── work/                # 过程工程缓存 (scene.html、dialogue_mix.wav、timeline.json)
└── outputs/             # 交付成果物
    ├── final.mp4        # 按确认的画幅/帧率导出 (无爆音/无截断)
    ├── subtitles.srt    # burn-in/sidecar按需交付；none无活动字幕，旧文件可存档
    ├── cover_4x3.png    # 1200×900 独立构图横版封面
    ├── cover_3x4.png    # 900×1200 独立构图竖版封面
    └── publish.md       # 多平台文案与标签
```
