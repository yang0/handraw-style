# 知识长卷制作指南

> **版本**：v1.0  
> **适用**：用户选择连续画卷讲知识、机制、历史或过程；制作模式仍为`scroll`。  
> **状态**：制作规范；本次未新增引擎接口，未制作知识长卷验证片。

与[长卷手册](unbounded_scroll_director_guide.md)同读，素材和坐标遵循[共用契约](frame_and_asset_contract.md#22-知识长卷的解释素材与坐标)。

## 1. 用画卷解释什么

先写“看完后观众能够解释什么”，据此确定事实范围、先备知识和需要看见的过程。以“问题 → 观察 → 过程/关系 → 原因 → 结论”组织内容，按题材调整，不强制每段重复五步。

| 组织方式 | 画卷承担的作用 | 解释重点 |
| --- | --- | --- |
| 时间 | 沿途展现历史、阶段或状态演变 | 时间标记、前后差异、变化原因；并列事件不伪装成因果 |
| 空间 | 沿河流、生产线或系统路径移动 | 来源、去向、连接和分支；横向排列不默认表示真实地理关系 |
| 因果 | 一个条件改变，触发后续过程 | 条件、机制、中间状态与结果；区分相关和因果 |
| 尺度 | 从整体推近到内部，再返回整体 | 尺度/层级说明、局部与整体关系；示意比例明确 |

角色可以是观察者、实验者或叙事线索，也可以没有角色。需要角色时安排与知识有关的行动和反馈；物理过程可以自行发生，不必都由角色触发。一个画风可贯穿整片，跨画风仅在章节、时代或解释目的需要时采用。完整过程可以停下来讲，也可以局部推近或用插入视图；连续画卷不要求镜头匀速前进。

## 2. 制作顺序与知识分镜

学习目标与受众 → 事实/来源与解释链 → 连续世界布局 → 口播、事件与镜头 → 素材/解释层 → 合成与知识验收。

先确定全片视觉和运动方向，再写分镜。已有用户授权按其范围执行；示范主题不自动成为新片选题。

每段在`design.md`记录以下字段，保留事实与画面间的对应：

| 字段 | 内容 |
| --- | --- |
| 知识点与观众所得 | 一个明确问题或结论、与前后段的关系 |
| 事实与来源 | 可核查出处及适用条件；时效内容记录日期；未知项先核实 |
| 可见证据 | 哪个对象、过程、中间状态或对比让观众理解；艺术装饰另记 |
| 口播锚点 | 对应短语/关键词和实际音频起止；说明词级或短语级精度 |
| 过程事件 | 初始状态、开始、关键变化、完成、最终保持；复杂过程列中间阶段 |
| 解释图层 | 对象、标签、箭头/路径、数值/单位、来源和简化说明，逐项对应素材或代码 |
| 镜头与停留 | 世界位置、当前焦点、行进/停留/推近、完整过程可见范围与结果阅读区间 |
| 素材与实现状态 | 来源/路径/锚点；设计、待素材、待接入、已接入、已验证、待用户审看分别记录 |

不要只把旁白分句配风景，也不要仅以角色走过几个世界作为知识覆盖证明。每个关键结论应有解释证据；纯口头总结可以作为有意的收束。

## 3. 解释图层与信息阅读

- **概念配色稳定**：同一颜色跨段表示同一概念；必要时同时给文字或形状编码。画风变化不得使知识对象失去对应关系。
- **一屏一个主焦点**：对象/结构先出现，再展开过程，最后标注结论。每次新增信息按讲解顺序出现，其余层保持稳定；按阅读量控制密度。
- **箭头有明确含义**：标明是在讲流向、因果、顺序还是指向；同一图里含义变化须说明。数值、单位、来源和比例保持准确，时间/空间压缩或示意明确标注。
- **解释层可编辑**：术语、标签和数据独立排版；生成图负责环境或对象形象，避免把生成文字当准确知识标签。复杂关系使用可核对的矢量层或分层图。
- **局部与整体可关联**：推近前让观众知道位置，推近后保留必要参照；结束可拉远总结关系。背景位图大幅放大会糊，按素材分辨率选择倍率或另制局部素材，不承诺任意无损缩放。
- **结果完成后再读**：阅读时间从全部必要信息出现后计算；不要把动画展开时间计入完整结果停留。过程和阅读未完成时镜头不提前移走。
- **字幕分工**：图内标签负责命名与关系，解说字幕按[字幕手册](subtitle_and_information_guide.md)选择；字幕关闭不删除内部语音时间线或知识标签。避免文字、箭头与关键状态被字幕遮挡。

## 4. 实际口播驱动事件

初稿可用预计时长规划；配音完成后按实际音频及ASR/服务时间边界映射锚点。配音分组按用户指定服务与实际工作流，保留自然停顿，不强制填满所有语音空隙。

区分三条记录：原始语音边界、过程事件时间、相机/解释层时间。需要先展示对象再解释时，可以提前构建结构；关键变化与对应短语协调，结果保持可以覆盖句间留白。不要修改ASR原边界来迁就画面；素材变化后更新事件映射。

事件用稳定ID和语义锚点组织，时间来自本期真实音轨；事件链包含依赖，例如“对象到位后开始流动，流动完成后显示结论”。下面是设计记录范例，**不是当前CLI读取的配置**：

```text
事件 condensation
语义锚点：口播“凝结成小水滴”
画面前提：云层局部已进入镜头
过程：示意水汽进入 → 小液滴逐渐显现 → 保持结果
解释层：显示“凝结”，说明云由小水滴或冰晶组成
相机：先到位，过程与阅读结束后继续前移
实现状态：待本期接入；时刻由实际音频映射
```

预览与编码均由绝对时间计算状态；保留可定位任意时刻的渲染接口，如现有期内`renderFrame(t)`。种子随机、事件依赖和镜头状态不能依赖播放次数。实际接入后检查正向、回跳和重载一致性。

## 5. 完整分镜示例：一滴水的旅行

**学习目标**：能说明水在水面、空气、云和陆地之间转移的基本过程。采用同一水彩画风，以水的状态和位置作为连续线索；无需旅人。此表为设计范例，时间待实际口播后确定，未生成素材或渲染。

| 段落 / 知识点 | 口播锚点示例 | 可见过程与解释层 | 镜头及结果停留 |
| --- | --- | --- | --- |
| 1 问题与全貌 | “水离开河面后，去了哪里？” | 先给河流、天空、山地的整体关系，提出观察目标；不一次展开全部箭头 | 全景建立位置，再聚焦水面 |
| 2 蒸发 | “液态水变成水蒸气，进入空气” | 日照环境中示意水离开水面，标签“蒸发”；上升符号标为示意，水蒸气本身不可见，不画成真实白烟；蒸发不必等到沸腾 | 在水面到空气之间停留，完整展示转移和标签 |
| 3 凝结 | “水蒸气冷却后，可以凝结成小水滴” | 镜头进入云层局部，示意小液滴形成，标签“凝结”；说明云由小水滴或冰晶组成，区别于水蒸气 | 保留云层参照，推近过程，完成后阅读 |
| 4 降水 | “云中的水以雨或雪等形式落下” | 本例展示雨滴向地面运动，标签“降水”；说明这是雨的示例，不将所有降水都画成雨 | 拉回云与山地，落点始终可见 |
| 5 回流与分支 | “一部分汇入河流，一部分渗入地下” | 地表水流向河流，并用局部剖面展示入渗；两条路径依次出现，标签“地表径流”“入渗” | 先看地表，再看剖面，保留两路结果 |
| 6 总结与自检 | “回看这条路径，蒸发和凝结有什么不同？” | 拉远显示已建立的关系，保留稳定概念色与标签；注明“简化示意，非唯一水循环路径”，不宣称每滴水都走同一闭环 | 展示完整关系后留出回答时间，完成总结 |

制作时另记录本期知识来源与适用条件。相邻场景的连接需要保持过程对象和状态关系；不能用景观叠化代替水的转移。可见示意对象只是知识表达，不将其艺术轨迹作为精确物理模拟。

## 6. 知识与技术验收

1. **知识覆盖**：逐条对应学习目标、口播和可见解释；检查前提、术语、因果、时序与最终结论。事实来源可追溯，数据和示意区分明确。
2. **误解检查**：隐喻、简化、比例和时间压缩是否会引出错误理解；历史前后变化不默认等于因果，示意状态不冒充观测数据。
3. **过程可读**：对象初始、中间和结果都可见；响应发生在正确条件之后；箭头含义清楚，跨段对象与状态连续。
4. **声画对应**：检查关键短语前后、事件开始/结束、标签完成和阅读中段；相机先到位，过程未结束不移走。动态观看并听审，不能仅靠ASR和静帧判断节奏。
5. **画框与文字**：目标画幅分别检查字体实宽、标签遮挡、字幕安全区、局部推近和整体总结；一屏信息无法阅读时拆解，不用无限缩字解决。
6. **技术证据**：沿用长卷的加载、图层、回跳/重载、尺寸、帧数、解码和音频检查。固定镜头或分层检查确认解释对象确实改变，背景横移帧差不证明知识过程成立。
7. **交付状态**：制作记录列出已接入与已验证的效果、未解决限制及审看状态。机器通过、完整动态审片和用户接受分别记录。

## 7. 当前能力与迁移边界

| 内容 | 当前状态 | 首次制作需做的工作 |
| --- | --- | --- |
| 通用长卷背景拼接、横移、标题/字幕 | 已有模板，实际边界见长卷手册第5节 | 核对本期画幅、素材、相机与文字 |
| 角色动作、接触、环境反馈、分层视差 | 《让画回应你》有期内实现与技术/抽帧证据 | 按新内容适配；不认为通用模板已升级 |
| 知识分镜、解释层、语义锚点、知识验收 | 本指南新增规范 | 准备素材及事实来源，接入本期渲染链路并验证 |
| 通用动态标签避让、关系/剖面图层、关键词驱动事件接口 | 尚未作为通用能力接入 | 核对可复用实现，补充适配或引擎代码，再登记证据 |
| 知识长卷端到端成片效果 | 尚无本分支实片验收 | 经授权制作完整知识案例，动态审看后记录结果 |

参考工程的解说片段与长卷骨架现已迁入本包，入口与手绘适配见[综合艺术动画指南](art_motion_integration_guide.md)。两者仍是不同表达路线：九类语法可以作为知识解释段，连续知识长卷需要本期过程对象、解释层、口播锚点和镜头；迁入引擎不等于知识长卷案例已完成验收。不依赖原参考目录运行，不复用其作者身份图片，也不照搬每幕必须运动或固定帧数等规则。
