# 🎬 动态漫导演手册 · 2.5D 视差剧场标准 (Motion Comic Director Guide)

> **版本**：v1.2  
> **适用技能**：`handraw-video-producer` (模式：`comic` / `theater`)  
> **核心原则**：按题材与可用素材选择表演层级。分层2.5D舞台适合姿态/道具表演；用户已确认的多关键画面有限动态漫也可用景别、气氛与运镜讲故事。两者都不自动具备连续肢体动画或口型同步，不以微缩放冒充完整人物动画。

本手册第1–4节的3×2图集、竖幅舞台与弹簧气泡是分层喜剧的具体制作方案，不是所有动态漫的素材前提。横屏叙事、严肃旁白或已有多画面作品沿用其确认的画幅、素材和字幕方式；不为套模板重做图集或改成喜剧。配音演播、时间线重对齐和切点修订时另读[跨模式声画与版本修订指南](audio_transition_revision_guide.md)。

## 一、 核心架构与表现力层级

为了让手绘作品展现出真正的动漫生命力，动态漫由以下 6 大解耦图层与控制管道构成：

```mermaid
flowchart TD
    subgraph 舞台渲染层 (2.5D Stage)
        BG["Layer 0: 纯净环境背景 (9:16 无人物无道具)"]
        PROP_UNDER["Layer 1: 背景关联道具 (如沙发上的坐垫)"]
        CHAR["Layer 2: 角色姿态 (Sprite Atlas 3×2 动态切换)"]
        PROP_OVER["Layer 3: 动作手持道具 (跟随肢体做贝塞尔位移/旋转)"]
        FX["Layer 4: 漫画特效 (无语黑线 / 冷汗水滴 / 抖动拟声词)"]
        BUBBLE["Layer 5: 弹簧台词气泡 (区分实体说话 / 听筒通话)"]
    end
    subgraph 音画协同管线 (Audio & Time Engine)
        TTS["指定配音或复用音轨 (实际语音边界)"]
        EQ["角色声学滤镜 (电话高低通滤波 / 空间混响)"]
        SFX["自适应拟音 (布料摩擦 / 提示短音 / 尴尬音效)"]
    end
    TTS --> BUBBLE
    EQ --> CHAR
    SFX --> FX
```

## 二、 素材生成与提示词工程规范

### 1. 纯净环境背景层 (Background Layer)
- **画幅规格**：按用户确认的输出比例；以下分层舞台示例为竖幅9:16 (1080×1920)。
- **构图原则**：
  - 中景或平视微俯视，整体平涂加松弛手绘黑线。
  - **视觉留白**：中央 50%~75% 高度留出角色站立或坐姿表演区域；上方留白用于容纳台词气泡。
  - **严禁污染**：画面内**绝不能出现任何角色、手、手机、包、关键动作道具、对话气泡或文字**。
- **提示词标准模板**：
  ```text
  风格名称：[风格名称，如 Friendly Girl-Diary Cartoon]。参考作者/风格编号：[如 FD-020]。核心风格特征：[松弛黑色手绘轮廓、简单平涂色、生活感]。主题色：[C-09 薄荷绿]，[C-30 象牙白]辅助。用途：动态漫画的单独场景背景层。竖幅9:16。[场景描述，如：一个小客厅，薄荷绿低矮沙发在画面下半部偏左，右下方简洁木色茶几；后方是象牙白墙面]。平视轻俯视，温暖日光。沙发在纵向画面约60%处，地面延伸到底部。前景中间留出站立角色的表演位置，上方墙面留给后期对白气泡。画面纯净，无任何人、无手持物、无包、无道具、无文字、无画框、无阴影人物，无logo。画面本身是完整空间，不要海报边框。
  ```

---

### 2. 角色姿态与独立道具图集 (3×2 Sprite Atlas)
- **画幅规格**：横幅 3:2 (如 1536×1024 或 1200×800)。
- **网格规约**：严格 **3 列 × 2 行**，共 6 个等大正方形隐形单元（无边框、无分割线、纯透明背景）：
  - **Cell 0 (上排左)**：姿态 1 —— 基础动作 / 日常站姿 / 开始搜寻
  - **Cell 1 (上排中)**：姿态 2 —— 深度动作 / 弯腰倾斜 / 动作变化
  - **Cell 2 (上排右)**：姿态 3 —— 反应停顿 / 瞬间呆滞 / 惊讶石化
  - **Cell 3 (下排左)**：姿态 4 —— 情绪反转 / 尴尬心虚 / 破涕为笑
  - **Cell 4 (下排中)**：独立道具 A —— 如被翻开的抱枕、外卖盒、被移开的杯子
  - **Cell 5 (下排右)**：独立道具 B —— 如打开的帆布包、笔记本电脑、钥匙串
- **角色一致性锚定规则**：
  - 必须详尽锁定：**发型**（短黑波波头/单马尾）、**服装剪影**（薄荷绿宽松T恤+深灰长裤）、**比例**（三头半身自然漫画比例）、**五官**（黑点眼睛+细线眉毛）。
  - **持握物连续性**：若角色设定为“右手始终持握手机并贴耳”，则 4 个姿态中该手持物必须完全一致，绝不允许凭空消失或换手！
- **提示词标准模板**：
  ```text
  风格名称：[风格名称]。参考风格编号：[如 FD-020]。核心风格特征：[与背景严格相同]。主题色：[同背景主题色]。用途：同一原创角色的四个动作关键姿态与两个独立道具，制作有限动画，真正透明背景PNG sprite atlas。横向3:2画幅，严格三列两行，共六个等大的正方形隐形单元，留透明间隔，没有格线，没有编号，没有文字，没有背景或地面。每个图形完整落在自己的单元内，不能跨越边界。角色相同：[角色一致性特征详述]。每一人物均全身、同一尺寸、同一头发衣服。脸和身体基本朝向镜头。[特定连贯动作规范，如角色右手始终把深色手机贴在右耳]。上排左：[姿态1描述]。上排中：[姿态2描述]。上排右：[姿态3描述]。下排左：[姿态4描述]。下排中：[独立道具A描述]。下排右：[独立道具B描述]。透明alpha必须真实，没有白色背景或灰色棋盘格烘焙，没有投影，四个人物是同一个角色的四个姿态，不是不同人。
  ```

## 三、 分镜头导演编排与舞台调度 SOP

### 步骤 1：剧本与节拍切分 (Beat Cutting)
- 不按机械时间切分，按**叙事事件与戏剧节拍**划分镜头（每段通常 3~5 秒）。
- **喜剧与反转关键定律 (Deadpan Pause)**：
  - 搞笑日常漫切忌“对白连珠炮”；
  - 在“对方点破真相”或“反转降临”的一瞬，可从0.6–0.8秒动作冻结与声音留白试起，按对白与动作调整；该手法不强制用于严肃旁白或其他题材。

### 步骤 2：多角色声学对齐与拟音 (Audio & Foley)
1. **实际语音驱动对白**：
   - 用户指定服务或音色优先；按角色、语义段或演播转折组织合成，不强制逐句请求。时间边界取自服务或实际音频对齐，精度以数据为准，不能因字段单位为毫秒就声称毫秒级准确。换配音后重新检查字幕、镜头和音效锚点。
2. **多角色与通话声学滤镜**：
   - 面对面/主角声音：原声输出；
   - 电话那头/对讲机/心声：施加电话 EQ 滤镜：
     ```bash
     highpass=f=280,lowpass=f=3400,volume=0.95
     ```
3. **本地拟音 (Foley)**：
   - 翻找动作：布料摩擦噪波（`cloth`）；
   - 突然顿悟：高频叮声（`hint`，740Hz~980Hz）；
   - 尴尬冷场：下行顿音（`awkward`，320Hz->190Hz）。

### 步骤 3：舞台视差与相机运镜 (Camera & Parallax)

以下四镜与缩放数值是分层喜剧示例，不固定其他题材的镜头数、顺序或幅度。按实际人物大小、关键道具、画幅与安全区确定运镜。

**多场景与连续性**：按剧情动作及空间关系安排地点，每个场景应有可辨识的环境与动作目的，不以同背景换裁切冒充多场景。新增背景锁定当前风格、色调、光线与透视，角色及关键道具身份保持一致；逐姿态核对手机/眼睛/手等锚点，不能假设不同图集单元共享坐标。若表现为同一角色持续在场、环境换景，可只衔接环境层、连续绘制角色，避免重复叠化两个人物；剧情需要人物交接或明确硬切时另行设计。背景已有家具不再复制一件漂浮前景家具，独立道具应有合理的接触、遮挡和动作关系。没有行走/肢体素材时声明姿态切换及有限动画，不把换房间或运镜当作完整行走。

- **镜头切换策略**：
  - 镜头 01（开场建立）：中景，全景平视，角色与环境全貌。
  - 镜头 02（动作加剧）：平移跟随主角动作，道具（抱枕/包）做贝塞尔曲线翻飞位移。
  - 镜头 03（关键转折）：**相机平滑推近至近景（Scale 1.48~1.50）**，聚焦主角神情与手部。
  - 镜头 04（结语释怀）：特写维持，表情微调，汗滴显现。
- **呼吸感物理律动**：
  - 角色在焦虑搜寻时，叠加 `dx = 8 * Math.sin(u * 8)` 的微幅频率抖动，强化慌乱感。

### 步骤 4：弹簧漫画气泡系统 (Spring Pop Bubbles)
- **入场物理弹簧曲线**：
  ```javascript
  // 气泡弹入：0.86 (压缩) -> 1.06 (过冲) -> 1.00 (稳定)
  const elapsed = t - cue.start;
  const p = clamp(elapsed / 0.16);
  const pop = p < 0.7 ? 0.86 + 0.2 * ease(p / 0.7) : 1.06 - 0.06 * ease((p - 0.7) / 0.3);
  ```
- **说话人样式区分**：
  - **角色现场说话**：可用实心圆角气泡，尖角朝向人物嘴部/头部。
  - **电话/场外声音**：可用虚线或区别色气泡，朝向电话/扬声器等真实声源；没有画内声源时采用场外语音标识，不虚构一个人物。
  - 上述色值、虚线样式和弹簧幅度是示例，沿用已确认画风或题材的表达。

**气泡避让与指向**：

- 指向是方向信息，不要求尖角延伸到嘴部或手机。优先短尖角与明确朝向；需要长引线时，设计绕行路径，而非穿过头发、五官、持物或文字。尖角长度、位置与留白由当前角色尺度、画幅和阅读区确定，不复制其他期的像素阈值。
- 分清素材坐标、角色/世界坐标和最终屏幕坐标。将当前姿态的头脸保护区域与声源锚点经过相同的角色位移、缩放和相机变换；气泡在屏幕空间绘制时用变换后的锚点。以最终形状检查避让，不把安全尖端坐标当作整条曲线安全。
- 保护区优先覆盖头发外轮廓、五官及关键持物；可用保守包围框或轮廓，按镜头大小留余量。气泡本体、完整尾部、描边/衬边、入场过冲与退出运动都参与检查。排布冲突时移动或重排气泡、缩短/绕行尾部，不能只把角色表情遮住或删掉对白。
- 本体与尖角保持同一变换、透明度和描边节奏；可用一条连续轮廓避免尾根双描边/接缝。检查现场对白与电话对白两种样式，以及弯腰、站立、近景、姿态交接时的表现。

### 步骤 5：漫画特效与拟声词 (Manga FX & SFX)

按情绪与剧情选择反应线、冷汗、速度线、拟声词等，不强制每条视频都有同一套符号。用户认可或要求保留的表现应作为修订保留项；优化场景、气泡或配音时不要静默删去或弱化。以下是可选的喜剧表达，不是全局模板：

- **反应线/无语线**：顿悟、震惊可用头外放射线；无奈可用额角短线。选择观众能辨识的轮廓与对比度，不能让黑线融进深色头发。可用错位、淡色衬边或调整粗细，而非统一加粗所有特效。
- **冷汗水滴**：心虚时在额角旁弹入、轻滑、保持，再按语义收束淡出；淡青色及贝塞尔形状仅为示例。可以有意贴在额角/头发上，但避开眼睛、嘴部、关键持物；不要为“完全无重叠”把汗滴推得远离角色，失去情绪归属。
- **拟声词**：在真正动作/声音事件处出现，随当前画风选择文字或图形；有抖动、旋转时检查峰值范围，不重复增加无意义装饰。

**锚定与运动契约**：

特效跟随当前姿态的额角、头轮廓或动作道具锚点，而不是固定房间坐标。可在角色空间跟随相机，也可将锚点投到屏幕空间以保持可读大小；不要混用两种变换造成漂移。没有检测器时如实称为人工标定的锚点/包围框，不宣称自动人脸追踪。

为所选特效给出可见状态：`触发 → 入场 → 峰值/运动 → 可读保持 → 退场`。具体时长取决于语义、动作和阅读，不套固定秒数。冻结角色表演与漫画符号运动分开控制；需要反应线仍轻抖时，角色可保持冻结，特效使用自己的局部时间，不改变静音留白。需要整个画面冻结时则同时冻结相关层。

从绝对时间确定状态，抖动使用确定性函数或固定种子，不用实时计时器驱动导出。验证汗滴下滑时比较它相对头部锚点的位移，避免把角色平移当成汗滴动画。Canvas经典脚本的调试入口使用独立名称，避免覆盖同名全局函数后递归调用。

## 四、 自动化渲染与交付质检清单 (QA Checklist)

在成片交付前，必须核验以下项目：

1. **画面逻辑核查**：
   - 核心道具（如手机）从第 1 帧起清晰可见，避免“凭空冒出”。
   - 角色左右手分工明确，无动作穿帮或道具移位。
2. **气泡与字幕核查**：
   - 气泡引线是否指向正确声源（现场人物 vs 电话听筒）。
   - 气泡文本与实际语音边界对齐，旧气泡在下一句开始前合理退出；按实际记录声明句级或词级，不声称未实现的口型同步。
   - 气泡已有完整对白时避免重复长句字幕；旁白型有限动态漫可以使用可读字幕，按画幅检查安全区。
   - 检查气泡本体/完整尾部与变换后的保护区，覆盖弹入峰值、镜头推近、姿态交接及退场；保守几何检查通过后仍复核实际画面。
3. **音画与节奏核查**：
   - 喜剧笑点检查留白与抢话，严肃叙事检查阅读与情绪收束；不以统一停顿阈值代替试听。
   - 检查最终混音的响度、真峰值、爆音与截断。`volumedetect`均值dB不是综合LUFS；目标随渠道选择，详见跨模式指南。
4. **封面独立构图**：
   - 自动生成 4:3 (1200×900) 与 3:4 (900×1200) 双版本封面，具有大字标题与醒目角色神态，并非随意截取某一视频帧。
5. **漫画特效与局部回归**：
   - 先查触发条件、可见窗口、锚点、层级及颜色，区分“代码存在”与“观众能看到”。采样特效前一帧、入场、峰值、运动中段、保持及退场后；记录反应线数量/可见性、汗滴相对锚点位移等实际证据。
   - 短片、快速过冲或姿态变化密集时可逐帧检查几何；长片按风险窗口加密。阈值随输出大小及画风选择，不强制沿用某一期的帧数、像素、汗滴位移或反应时长。
   - 回跳重渲染一致，核对改动外的场景、人物、气泡、漫画特效、配音、字幕及节奏仍保持；动态观感需实际播放，静帧/几何证据不替代动态观看或用户验收。

## 五、 局部案例与泛化边界

`videos/episodes/2026-10-08 找手机找了个寂寞/`：`bubble_revision.py` / `scene-v3.html` 演示短尖角及变换后的头部避让；`fx_revision.py` / `scene-v4.html` 演示头外反应线、角色锚定汗滴、特效运动采样及旧音轨复用。输出检查在相应 `outputs/revision_v3/`、`outputs/revision_v4/`。

这些是期内脚本，含角色坐标、具体台词、三场景、图集采样和固定资源路径；不是通用CLI能力。可迁移的是坐标空间一致、指向与接触分离、特效随语义锚定、局部修订保留表现与分层验收，不是该片的长度阈值、留白、帧数、配音音色或特效数量。技术与静帧复核通过，用户审美验收另行记录。
