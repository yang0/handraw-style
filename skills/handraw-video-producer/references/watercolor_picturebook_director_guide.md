# 水彩纸纹绘本导演手册

> 版本：v1.2 · 2026-10-08  
> 所属：`handraw-video-producer`，模式 `story` / `watercolor` / `picturebook`。

适用于绘本新制作与已有绘本的切页、节奏修订。目标是画面连贯、阅读从容，而不是每页堆叠特效；插画配微运镜和环境动效不等于完整人物动画。

## 一、 全片视觉与阅读节奏

- 沿用用户选定的风格、画幅与构图。纸页留白和全屏铺满都是可选方向；不要为了模板默认外观改变已确认的布局。
- 角色身份先锁定：外形、服装、主道具与颜色跨页一致。连续页用同一参考锚点，切页不是掩盖角色漂移的手段。
- 纸纹、轻微推拉与环境动效服务故事。雨景使用雨滴和水纹，晴天才考虑光斑；环境层不要落在伞下角色或遮挡文字。不强制铅笔反复画框、逐字打字或马克笔刷重点。
- 文案采用可读的完整短句或分行段落。不要机械地只保留逗号拆分后的前两句；旁白、页内文字与字幕各有用途，但故事信息不应因排版丢失。
- 时长依据实际配音及阅读留白确定，不机械均分每页或拉伸到某个整数。改转场时，保留原叙事、音轨、字幕时间线和总时长，除非用户另有要求。

## 二、 一个切点只有一次衔接

### 常见失败与修正

旧图先卷纸退出或淡出至空白，新图又从灰色草稿开始水彩显现，会让观众感到“切了两次”。不要把退出和入场当成两个独立动画串联。

- 默认让完整旧图直接承接完整新图；选择一段叠化，或一段以旧图为底的水彩替换蒙版。
- 水彩从纸面显现可用于开场。页间采用叠化时，不再重置为浅灰线稿、空白纸或再次执行显现；只有用户明确要求重绘过程时才采用该叙事效果。
- 旧图、新图及各自的雨滴等附属层应一起衔接；全局纸纹可保持稳定，避免额外的退出、闪白或环境层骤停。文字保持独立可读，必要时单独检查切点前后字幕时机。
- 图像蒙版和叠化是视觉模拟；未实现物理水彩或噪声算法时，不将其描述成物理仿真或 Perlin 洇染。

### 时长与时间线约定

舒缓绘本可从 **2.0秒**单次叠化起步；短镜头或快节奏可缩短。用户指定优先，不把2秒设为所有模态的固定规则。长叠化会使差异较大的角色轮廓短暂重叠，需检查实际画面。

设原切点为 `cut`，完整转场时长为 `d`：

```text
start = cut - d / 2
end   = cut + d / 2
u     = clamp((t - start) / d, 0, 1)
p     = u * u * (3 - 2 * u)
最终图像 = (1 - p) * 旧图 + p * 新图
```

这是一段总计 `d` 秒的衔接，不是旧页退出 `d` 秒加新页入场 `d` 秒。先画不透明旧图，再按透明度 `p` 叠加新图，或分别渲染到离屏缓冲后加权合成；不要把旧图先画成半透明底再重复叠加，造成画面变暗或露出空白。

转场嵌入原时间线，不向总片长逐次追加 `d`。若相邻转场窗口重叠、超出片头片尾，需缩短或重新安排窗口；用户明确指定时长且与现有镜长冲突时说明冲突，不静默替换。

期内可用 `transition_seconds` 保存时长；配置必须实际传入模板和渲染脚本，元数据、检查结果与预览描述保持一致。

**实现边界**：这是导演配置约定，不是新增的 `hvp` CLI 参数。目前通用 `lib/modes/story_template.html` 仍使用写死的1秒入场叠化，`hvp.py` 不会自动读取上述字段；期内脚本需显式支持或适配后才能声明参数生效。不要只改文档或 `episode.json` 就声称已改变成片。当前修订范例的 `produce.py` / `revise.py` 已显式注入该字段。

## 三、 素材、配音与局部修订

指定配音、重新演播或音轨变化时，另读[跨模式声画与版本修订指南](audio_transition_revision_guide.md)：核验实际服务参数，按新语音重对齐字幕/镜头/音效，区分服务端语速与后期变速。下列复用音轨规则适用于音频无需变化的修订，不阻止用户授权重配。

- 按实际本地风格库核验风格编号和名称，不沿用未核验的示例映射。画面提示词描述角色、场景、色彩、纸感与裁切安全区；排版文字由后期合成，插画不生成字幕或气泡。
- 用户指定火山配音、音色或已有音频时遵从该选择，不自动换回 Edge-TTS。记录服务原始时长、后期变速和实际放置时间；服务语速参数不等于最终后期速度。
- 字幕依据实际音频起止校准。逐段 ASR 边界不是逐字时间戳，恢复文本后仍需检查断句和时间范围；没有口型动画则不宣称口型同步。
- 只改画面时优先从上一版复制音频流，避免重新合成或重编码带来变化。格式不兼容需要重编码时，说明原因并验证内容与时序，不声称音轨字节相同。
- 输出 `outputs/revision_vN/` 或等价版本路径，保留旧片和可复现源配置。期内有版本化脚本时用该脚本；不要用全量 `build` 覆盖现有成果。隐藏浏览器逐帧渲染仅作用于本期工程，不修改外部配音项目。

## 四、 导出与验证

先检查少量静帧，再导出全片；技术通过与用户接受分开记录。

1. 每处转场建议采样 `cut-d/2`、`cut-d/4`、`cut`、`cut+d/4`、`cut+d/2`，确认只发生一次衔接，权重单调且和为1，没有非预期空白、闪白、裁切跳变或角色漂移。
2. 对同一时刻先渲染、跳至另一页、再返回，比较结果；需要跨运行可复现时，粒子与纸噪使用固定种子而非未固定的 `Math.random()`。场景内局部时间和镜头进度需截断到有效范围，避免叠化时旧图超时运镜或新图负时间回弹。
3. 图片和字体加载成功后再推帧；资源失败或浏览器错误不能作为黑帧继续交付。检查文字测宽、安全区及阅读留白。
4. 以高质量JPEG推流可减少序列化开销，但模板输出格式与FFmpeg输入编码必须一致；QA静帧可保留PNG。已有PNG流程不必为局部修订强制迁移。
5. 用 ffprobe 核对分辨率、帧率、帧数和时长，预期帧数为 `round(duration * fps)`；用FFmpeg完整解码检查，不只看文件存在。视觉复核还须观察转场，解码成功不代表观感通过。
6. 仅改转场时，对原稿、图片、字幕和旧视频核对哈希；音频采用流复制时比较压缩音频流哈希。不同封装的整个MP4哈希无需相同。
7. 验证通过后更新 `episode.json` 与 `preview.html` 的视频路径及描述。交付可播放的新版和绝对路径，保留旧版对比；未获得用户确认时标记待审。

## 五、 本次修订的实证范例

工作区工程：`videos/episodes/2026-10-08 一片叶子的屋檐/`。

- v1：旧页0.25秒卷纸退出，新页重新水彩显现；用户反馈像两次转场。
- v2：取消卷纸退出，开场保留水彩显现，四处切页各一次0.60秒叠化。
- v3：用户指定延长至2.00秒；以原切点前后各1秒衔接，总片长仍为34.1秒、1080×1920、30fps、1023帧。
- v3验证：四处切页共20个采样点，回跳一致、无中间空白；全片解码无错误；原稿、图片、字幕和旧视频不变，AAC音频流哈希与原版一致。记录在 `outputs/revision_v3/validation.json`、`transition_qa.json`，制作细节在 `production-notes.md`。
- 该记录证明技术完成，不代表用户已确认审美验收，也不代表通用模板已升级。

本工程的版本化执行例（不是通用CLI接口）：

```powershell
python "videos/episodes/2026-10-08 一片叶子的屋檐/revise.py" prepare 3
python "videos/episodes/2026-10-08 一片叶子的屋檐/revise.py" qa 3
python "videos/episodes/2026-10-08 一片叶子的屋檐/revise.py" render 3
python "videos/episodes/2026-10-08 一片叶子的屋檐/revise.py" finish 3
```

新工程仍可使用 `hvp.py new "标题" --mode story`。原创故事需准备与剧情相符的插图；通用风格样图可用于技术试播，不冒充原创故事素材。新制作与局部修订不要混用全量流程。
