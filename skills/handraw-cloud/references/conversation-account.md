# 自然语言账号交互与回复末尾状态

适用于手绘风完整安装包的全部用户可见回复，包括提示词、出图、配图规划、资源管理、分享和失败说明。Agent 操作脚本，用户直接说需求；正常对话不要求用户打开终端、复制命令、寻找资源 UUID 或提供密码/API Key。

## 账号操作

- “绑定手绘风账号”“登录手绘风”“连接官网账号”：先检查账号状态；已连接时显示实际用户名，只有明确换号/重新绑定才重新申请。未绑定时，Agent 从安装包根目录执行 `python -X utf8 scripts/handraw_cloud.py bind --start --no-browser`，把返回的 `verificationUrl` 展示为“绑定手绘风账号”的 Markdown 链接，宿主支持时直接打开该链接。说明“在网页登录并点击授权，回来告诉我‘我已授权’即可”。可以展示 `userCode` 方便网页输入。不要在聊天里等待十分钟，也不把内部命令作为用户步骤。
- “我已授权”“绑定好了”“继续绑定”：执行 `python -X utf8 scripts/handraw_cloud.py bind --check` 一次。若受轮询间隔限制，按 `retryAfter` 等待后再检查一次即可；仍 pending 就保留进度，告知尚未收到网站确认。仅 `state=connected` 才说绑定成功并展示真实用户名。网络暂不可用保留进度，不重新申请；expired/denied 时说明原因，引导用户说“重新绑定账号”。
- “查看账号”“我绑定了吗”：执行 `python -X utf8 scripts/handraw_cloud.py status`，用返回状态回答。
- “解绑账号”“退出绑定”：执行 `python -X utf8 scripts/handraw_cloud.py unbind`，说明只清除当前设备的绑定；若要撤销令牌，提供网站设备管理入口，让用户在网页操作。

所有脚本路径从当前安装包根目录解析；`.agents/skills` 可能是扁平入口或链接，先解析真实目录。status 只检查状态，不会自动开始授权、上传或发布。仅当用户表达绑定意图才申请授权。

## 每次回复末尾

1. 正常完成用户当前任务，本地创作不以绑定为前提。
2. 在最终回复前执行 `python -X utf8 scripts/handraw_cloud.py status`。本轮刚得到绑定/解绑结果时直接复用它，不重复查状态。不要读取或打印本地认证文件；脚本只返回可公开的状态。
3. 把返回的 `footer` 原样放在最后一行，位于成果、分享入口和原有画廊传送门之后。只放一行，不重复展开完整功能介绍。

- 未绑定：说明说“绑定手绘风账号”即可开始，以及同步私有图库、自建画风/图型、获取获准离线使用的收藏、分享作品和互动的好处。
- 等待授权：展示仍在等待，引导说“我已授权”。
- 已绑定：展示经网站核验的用户名，不再次推销绑定。
- 连接失败：按 unverified 表述“本机已保存绑定，暂无法核验”，不说已解绑，不把缓存身份当成在线成功。
- 完整云模块缺失的独立安装包：简短说明“当前安装包仅支持本地创作，账号联动需完整手绘风安装包”；不虚构绑定链接或功能可用性。状态查询意外失败时说“账号状态暂无法确认，本地创作可继续”，不影响成果交付。

## 用自然语言完成联动

“备份我的图库”“恢复我的角色素材”“同步我的画风”“看看我的收藏”“分享这组图片”“查看评论”等请求由 Agent 读取相应子 Skill 并执行。若需要选择资源或作品，优先用用户可识别的名称和预览，不要求记 UUID。需要账号而未绑定时，引导完成上述网页授权；仅说“创建画风”或生成图片不等于同意上传或公开。

个人图库和自建资源同步仍私有。作品公开需用户明确请求；主动上传生成记录会公开图片与原始创作指令，须在执行前说明。不得因为账号已绑定而默认同步、上传、点赞或发帖。
