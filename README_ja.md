> **画風をうまく言葉にできない？ ビジュアルのレイアウトを組み立てるのに苦労している？ インデックス番号を選ぶだけで、ひと目でそれとわかる AI 画像プロンプトを生成できます。**

このリポジトリには、**365 種類の手描き・リアル系ビジュアルスタイル**（`FA`〜`FI` のカテゴリ ID と旧来の `001`–`368` の両方に対応）、**170 種類の構図レイアウトパターン**（`SC-*` ソーシャルカード、`IG-*` インフォグラフィック、`SB-*` 漫画ストーリーボード、`IP-*` IP デザイン、`EC-*` EC）、そして厳選した **36 色のクラシックな単色カラー**（`C-01`–`C-36`）を収録しています。

SNS 投稿のカバー、教育用インフォグラフィック、アーキテクチャの比較図、複数コマの物語漫画など、何を作る場合でも、難解な美術史の用語を覚えたり、複雑な構図に悩んだりする必要はもうありません。**スタイル番号、レイアウト ID、テーマカラーを選んでトピックを伝えるだけで、検証済みで再現度の高いバイリンガルのプロンプトがすぐに得られ、Midjourney、DALL-E 3、Flux、Stable Diffusion などの画像生成ツールにそのまま貼り付けられます。**

## 🌟 クリエイターの悩みと解決策

| クリエイターの悩み | このライブラリによる解決策 |
| :--- | :--- |
| **スタイルの説明があいまいで、画風がぶれる** | **番号によるインデックス**：体系的に分類された 368 種類のビジュアルスタイル（FA〜FI のカテゴリと 001–368 の二重インデックス）で、当てずっぽうのプロンプト作成をなくします。 |
| **構図が単調で、複雑な図版をレイアウトしにくい** | **170 種類のレイアウト構図**：ソーシャルカード 24 種、インフォグラフィック 38 種、漫画ストーリーボード 71 種、IP デザイン 13 種、EC 24 種をすぐに使えます。 |
| **配色がまとまらず、統一感のあるトーンが出ない** | **厳選した 36 色の単色カラー**：クラインブルー、セージグリーン、エルメスオレンジ、ペインズグレーなどで、ワンクリックで純粋かつ洗練されたトーンを設定できます。 |
| **文字と絵がかみ合わず、文字の配置が不自然** | **デュアルモードのワークフロー**：「純画像モード」（イラストのみ）と「図文モード」（文字と絵が一体になった構図）をスムーズに切り替えられます。 |
| **モデルがスタイルのキーワードを無視したり、画風の再現度が低かったりする** | **段階的なモデル適応とフォールバック**：ネイティブ対応モデルにはキーワードによる発動を調整済みで、サードパーティのモデルにはすべて参照画像フォールバック（4 分割シート）を自動で適用します。 |
| **記事のカバーが退屈で、ビジュアルが内容とかみ合わない** | **記事・動画カバーデザイナー**：記事や動画の字幕から約 200 字の要約と読者ペルソナを自動で抽出し、スタイルと配色を組み合わせ、視覚的なメタファーを優先し、動画カバーにはクリックしたくなるバズ向けの指示を加えます。 |
| **記事の挿絵に統一感がなく、レイアウト作業が面倒** | **記事挿絵プランナーと自動挿入**：編集者の視点で価値の高い 2〜5 か所の転換点を選び、記事全体を単一のスタイルと配色で統一し、画像を一括生成して Markdown の正確な位置に挿入します。 |
| **写真撮影の企画がまとまらず、AI のポートレートがありきたり** | **エディトリアル写真と時空のオーケストレーション**：10 以上のジャンル（カップル、ウェディング、ポートレート、家族など）に対応し、対照的な 3 つの時空プランを 8 分割画像用のキーワード付きのコピー可能なコードブロックで提案して、ワンクリックで生成できます。 |

## 🎯 対象ユーザーとユースケース

- **コンテンツクリエイター・インフルエンサー**：SNS のカバー（Xiaohongshu、Instagram、X/Twitter）、ニュースレターのヒーロー画像、バズる名言カード。
- **ニュースレター・長文記事の書き手**：約 200 字の論点の自動抽出、クリック率の高いカバーデザイン、統一感のある複数の挿絵の企画、Markdown への自動挿入。
- **写真家・ポートレートクリエイター**：10 以上のジャンル（カップル、ウェディング、家族写真、漢服など）のエディトリアルなスタジオ撮影の企画と、8 分割サンプルの即時生成。
- **ナレッジ・テック系ブロガー**：比較リスト、アーキテクチャのピラミッド、ステップごとの手順、エンゲージメントの高いインフォグラフィック。
- **漫画・ストーリークリエイター**：4 コマ漫画、エモーショナルなウェブトゥーン、ストーリーボードの下書き、子ども向け絵本の挿絵。
- **ビジュアル・ブランドデザイナー**：コンセプトの素早いスケッチ、クリエイティブなキャンペーンポスター、キャラクターデザインのプロトタイプ。

この Skill は、AI コーディングアシスタント（Codex、Claude Code、Cursor、WorkBuddy、OpenCode）に直接インストールできます：

> **"Install this Skill for me: https://github.com/yang0/handraw-style"**

アシスタントが自動でリポジトリをクローンし、すべてのスタイル、レイアウトテンプレート、参照アセットを設定します。

このパッケージは静止画のデザインに特化しています。動画制作、ナレーション、レンダリング、ショットギャラリーは、別プロジェクトの `handraw-video` に移りました。静止画の動画カバーのデザインは、引き続きここで利用できます。

## この Skill の使い方

### 1. スマートおすすめモード（手間ゼロ：ID は不要）
インデックスを見て回りたくない場合は、**描きたい内容を説明するだけ**で大丈夫です！ Skill がテーマの雰囲気、分野、文脈を分析し、**最も合う手描きスタイルと最適なクラシック単色テーマカラーを自動で組み合わせます**（美的な理由も添えます）：
- *パラメータなしのプロンプト*：`Generate a prompt for a healing illustration of a cat sunbathing on a windowsill, pick the style and theme color for me (can combine)`
  > 💡 *おすすめの組み合わせ*：スタイル `#FA-018 (#018) · Minimal Deadpan Dialogue Cartoon` ＋ カラー `C-26 · Persimmon Orange`（理由：温かく、ほっとする、くつろいだ雰囲気）で、すぐに使えるバイリンガルのプロンプトをその場で出力します。
- *補完*：スタイルだけを指定した場合（例：`Style FC-029 / 276, Theme: Future of AI`）、Skill が調和するカラー（例：`C-01 Klein Blue`）を自動でおすすめします。カラーだけを指定した場合は、合うスタイルを自動でおすすめします。

### 2. 精密な手動選択モード（具体的な ID を選ぶ）
1. [スタイル一覧シート（STYLES_en.md）](STYLES_en.md)、[レイアウト一覧シート（LAYOUTS_en.md）](LAYOUTS_en.md)、または[クラシック単色カラーシート（COLORS_en.md）](COLORS_en.md)を開いて一覧を眺め、使いたい番号を選びます；
2. 選んだ ID をメモします。例：スタイル `FB-006`（または旧番号 `041`）、レイアウト `SC-001`、テーマカラー `C-01`；
3. Skill にプロンプトの指示を送ります。例：
   - **スタイルのみ**：`Style: FB-006 (041), Theme: First milk tea of autumn`
   - **レイアウト＋スタイル**：`Layout: SC-001, Style: FB-006 (041), Theme: First milk tea of autumn`
   - **テーマカラー付き**：`Layout: SC-001, Style: FB-006 (041), Color: C-01, Theme: First milk tea of autumn`
4. 正確なスタイル定義、レイアウトの構図、統一された配色を含む、すっきりとしたコピー可能なバイリンガルのプロンプトを受け取ります；
5. Midjourney、DALL-E 3、Stable Diffusion、Flux などの画像生成ツールにコピー＆ペーストして作品を作成します。

### 3. AI ポスターデザインモード（構造化プロンプト、ネイティブな一体型レイアウト）
季節のキャンペーンビジュアル、キービジュアル、エディトリアルな SNS 用ポスターをデザインしたいですか？ ポスターのテーマを Skill に伝えるだけです！
- **プロンプトの指示**：`请帮我出海报提示词， 主题：秋分`（または `Generate a poster prompt for me, Theme: Autumn Equinox`）
- **インテリジェントな組み合わせ**：Skill がコンセプトを分析し、最も合う手描きスタイル（例：`#FE-053 (#268) · Contemporary Literati Ink Cartoon`）とクラシックなテーマカラー（例：`Dominant: C-26 Persimmon Orange + Accent: C-03 Prussian Blue`）を組み合わせます。**8 つの中核的なデザイン要素**（テーマ、シーン、受け手、情報密度、ムード、配色、エディトリアルスタイル、手描きスタイル）にわたる構造化されたすっきりしたプロンプトを、文字と構図を一体化させるためのガイドラインとともに出力します。
- **実際の生成例**：プロンプトをそのまま画像生成モデル（例：GPT Image 2/2.5）に渡すと、ネイティブな文字レイアウトと芸術的なメタファーが自然に融合した画像が得られます。大きな書道風のタイトル、詩的な対句の題字、落款印、昼と夜のバランスのとれたイメージ、そしてくつろいだ文人水墨の筆致が表現されています：

### 4. プロのコツ：万能のポスター思考（インフォグラフィックを高密度のポスターとして扱う）
用意されたインフォグラフィックのレイアウトに窮屈さを感じていますか？ **固定のグリッドに想像力を閉じ込めないでください！**
インフォグラフィックの本質は、情報密度の高いビジュアルポスターです。**時間帯、主要な指標、手順、利用シーン**を Skill に伝えるだけで、モデルがタイムラインの節目、風景のイラスト、文字を自然に織り込み、まとまりのあるエディトリアルなレイアウトに仕上げます：
- **旅行の行程表**：*チェンマイ 5 日間の気ままな旅（1 日目の行程）*（時間ごとのルート＋ランドマーク＋北タイ料理とヒント）
- **アウトドアのギアガイド**：*超軽量の山岳キャンプ用パッキングガイド*（3 つの主要システムを並べたノーリング＋8kg の上限、ワークウェア風）
- **暮らしのスキル**：*初心者向けハンドドリップコーヒーガイド*（1:15 の比率＋3 段階のパルス注湯のタイムライン＋フレーバーホイール）

💡 **[👉 クリックしてチュートリアルとプロのコツの完全ガイド（TUTORIALS_en.md）を読む](TUTORIALS_en.md)**（万能のポスター思考、動的なおすすめ、三要素の組み立て、デュアルモードの切り替え、複数モデルの段階的な使い分けを、コピーして使える完全なプロンプトとともに解説しています）。

### 5. 記事・動画カバーデザインモード（要約抽出、読者ペルソナ、視覚的メタファー、目を引くバズ向けカバー）
記事を書き終えたり動画を編集し終えたりして、クリック率が高くセンスのよいカバーが必要ですか？ 本文や字幕ファイルを Skill に送るだけです！
- **対象シーン**：WeChat 公式アカウントのカバー（`2.35:1` または `21:9` を推奨）、X/Twitter の記事カバー（`5:2`）、Xiaohongshu のカバー（`3:4`）、動画カバー／Bilibili／YouTube／ショート動画のカバー（横長 `16:9`、縦長 `9:16` または `3:4`）。
- **プロンプトの指示**：
  - 記事：`Please design a cover for this article: [paste article text or provide local file path d:\path\to\article.md]`
  - 動画／字幕：`Please design a video cover: [paste subtitle text or provide .srt/.vtt file path]`
- **自動化されたワークフロー**：
  1. **要約の抽出**：主要な論点、物語のフック、要点を約 200 字のエッセンスにまとめます；
  2. **読者ペルソナの推定**：知識の深さと動機を評価し、ターゲット読者のプロフィールを組み立てます；
   3. **スタイルと配色の組み合わせ**：365 種類のビジュアルスタイルと 36 色のクラシック単色パレットから最適な組み合わせをおすすめします（例：`#FA-018 (#018) Minimal Deadpan Dialogue Cartoon` ＋ `C-01 Klein Blue`）；
   4. **ネイティブなメタファーとバズ向けの指示**：
      - 記事カバー：実績のあるエディトリアルの指示を加えます —— *「まず視覚的なメタファーを設計してから画像を生成してください。メインタイトルは太く目立たせ、小さな文字は少なくするか入れないでください。それ以外のデザインはお任せします。」*；
      - 動画カバー／字幕入力：次の指示を必ず加えます —— *「動画カバーのデザイン。クリックされやすく、ネットでバズる魅力があり、視覚的に人を引きつけて目を引くこと。まず視覚的なメタファーを設計してから画像を生成してください。メインタイトルは太く目立たせ、小さな文字は少なくするか入れないでください。それ以外のデザインはお任せします。」*；
   5. **2 つのトラックでの納品ガイド**：
      - **トラック A（手動生成）**：生成されたバイリンガルのプロンプトを、お好みの画像ツールにコピーします；
      - **トラック B（完全自動）**：**「Auto generate cover」**と返信するだけで、Skill が画像生成ツールを呼び出してカバーのビジュアルを直接作成します。

### 6. 記事挿絵プランナーと自動挿入モード（ビジュアルの企画、統一感のあるアート、Markdown への組み込み）
文字ばかりの記事は読者を疲れさせ、離脱を招きます。かといってストックフォトを探すと、画風がばらばらになり、レイアウト作業にも手を焼きます。このモードは、**「編集視点での挿入箇所の選定 → スタイルと配色の統一 → 一括生成 → Markdown への自動挿入」**というエンドツーエンドの編集パイプラインを提供します：
- **プロンプトの指示**：`Please plan and generate illustrations for this article: [paste article text or provide local file path d:\path\to\article.md]`
- **自動化されたワークフロー**：
  1. **編集者の視点でのビジュアル判断**：段落ごとに機械的に挿絵を入れることはしません。物語の緊張感と概念の複雑さを理解し、価値の高い 2〜5 か所の転換点（主張の提示、抽象的なメタファー、構造の図解、クライマックス、結びの要点）を特定します；
  2. **単一スタイル・単一カラーによる統一感**：記事全体を単一の手描きスタイル（例：`#FC-029 (#276) Contemporary Literati Ink`）と配色（例：`C-01 Klein Blue`）に固定し、エディトリアルの標準である `4:3` のアスペクト比で仕上げます（余白は通常／やや広め／広めから選べます）；
  3. **構造化された計画とプロンプト**：正確な挿入位置のアンカー、挿絵の目的、画像の種類（`editorial illustration`、`conceptual diagram`、`metaphorical illustration` など）、ビジュアルのコンセプト、すぐに使えるバイリンガルのプロンプトを示します；
  4. **2 つのトラックによる納品の完結**：
     - **トラック A（手動生成と挿入）**：お好みのツールで画像を生成し、画像を貼り付けるかローカルパスを伝えると、Skill が Markdown の正しいアンカー段落の後ろに自動で挿入します；
     - **トラック B（完全自動の生成と挿入）**：**「Auto generate and insert」**と伝えるだけで、Skill がすべての挿絵を順番に生成し、内蔵の Python 挿入エンジンを起動して、整形済みの完成した Markdown ドキュメント（例：`article_illustrated.md`）を作成します。

### 7. プロの写真撮影企画モード（カップル／ウェディング／ポートレート／家族、3 つの候補プランと 8 分割画像の即時生成）
安っぽいスナップ写真のような仕上がりや、ありきたりな AI ポートレートとはお別れです！ カップル撮影、ウェディング撮影、個人のポートレート、家族写真、古風な漢服、旅のスナップのいずれを企画する場合でも、エディトリアルなスタジオの水準で、時空の設定、スタイリング、撮影手法を計画します：
- **対応ジャンル**：カップル写真、ウェディング撮影、個人のポートレート、家族写真、古風な漢服、新中華風、レトロな香港風、コスプレ、旅のスナップ、ビジネスポートレートなど。
- **プロンプトの指示**：
  `Photography mode, please first propose 3 candidate directions for me to choose from, shoot type: couple`
  *（または、Web のプロンプト組み立てツール [tutorials.html](skills/handdraw-style-prompter/gallery/tutorials.html) で「撮影」モードに切り替えます。テーマは任意で、指定しない場合は AI が多様な 3 つの時空を厳選します）*
- **自動化されたワークフローと主な特長**：
  1. **必ず最初に 3 つの案を提案**：地理と世界観が大きく対照的な 3 つの候補（現代の実在するランドマーク 2 つ＋タイムトラベル／歴史／未来／架空の世界 1 つ）を提案し、ユーザーの代わりに勝手に決めることはありません；
  2. **参加者ごとのスタイリングとメイクの決定**：参加者同士の関係、一人ひとり異なる衣装、確定したエディトリアルなヘア＆メイクを詳しく決めます（女性の被写体はデフォルトでソフトフォーカスのスタジオレタッチとし、本物の肌の質感と自然な光を保ちます）；
  3. **8 分割画像用のキーワード付きの独立したコードブロック**：3 つのプランはすべて独立したテキストのコードブロック（` ```text `）に完全に収められ、末尾は生成用のキーワード `出8宫格图片。` で終わります；
  4. **柔軟な 2 つのトラックでの生成**：
     - **【ワンクリックでコピーして生成】**：いずれかのコードブロックのコピーボタンをクリックしてプロンプト全文を取得し、Midjourney、Flux などの画像生成ツールに貼り付けます；
     - **【A / B / C と返信して即時生成】**：チャットで `A`、`B`、`C` のいずれかを返信すると、AI がその方向性の 8 分割サンプル画像をすぐに生成します。面倒な企画書を待つ必要はありません！

## 2 つのプロンプトモードを即座に切り替え

どの番号とテーマでも、スタイルを変えずに 2 つのモードをスムーズに切り替えられます：

- **純画像モード（纯图模式）**：画像内に文字を入れず、テーマに沿った絵だけで表現します。イラスト単体、壁紙、本の表紙、コンセプトアートに最適です。  
  *例*：`Pure-image mode, Style: FB-006 (041), Theme: First milk tea of autumn`
- **図文モード（图文模式）**：コピー文をそのまま残し、AI にメタファーを設計させて、文字をビジュアルの構図に調和させて組み込みます。名言ポスター、ミーム画像、ソーシャルカードに最適です。  
  *例*：`Graphic-text mode, Style: FE-052 (267), Theme: There are many things you couldn't figure out back then. Don't worry, give it some time and you might just forget about them.`

*「switch to pure-image mode」*または*「switch to graphic-text mode」*と入力すれば、いつでもモードを切り替えられます。指定がない場合は純画像モードになります。

### モデル適応の仕組み

デフォルトでは、Skill はコピー可能なプロンプトを作成します。画像生成を明示的に依頼した場合は、検証済みのモデルの能力に基づいて出力を最適化します：

- **明示的に調整済みのモデル（例：`gpt-image-2`）**：368 種類すべてのスタイルで、完全な発動の階層を使います：スタイル名／作者名 → 肯定的な中核の特徴 → 特徴だけではスタイルを確実に引き出せない場合に限り参照画像。不要な画像の受け渡しで構図が縛られすぎるのを防ぎます。
- **サードパーティ・汎用モデル（Midjourney、Flux、Stable Diffusion、Imagen、Gemini など）**：堅実な**参照画像フォールバック**戦略を使います。Skill が 1024x1024 の 4 分割の標準参照画像またはそのファイルパスを提供し、線の描き方、質感、配色を 100% 忠実に再現して、プロンプトによるぶれを防ぎます。
- **コミュニティによるベンチマークを歓迎**：能力の定義は `skills/handdraw-style-prompter/references/model_capabilities.json` にあります。他のモデルの評価のプルリクエストを大歓迎します！
