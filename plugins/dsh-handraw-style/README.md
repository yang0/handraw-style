# 手绘风工作台 · DSH 插件（0.5.0）

主仓库：[yang0/handraw-style](https://github.com/yang0/handraw-style)

这是放在 `handraw-style/plugins/dsh-handraw-style/` 的 **DSH 原生插件子目录**，不是独立项目。直接读取上级仓库的 368 款画风、170 种图型、36 种主题色及影调元数据、原始图片和图型 Markdown 模板；不复制素材，也不需要构建前端。参考 [dsh-handraw-style](https://github.com/yang0/dsh-handraw-style) 的跨面板存档思路。

## 功能与交互

- **创作台**：默认只展示一个 **画风** 选择；勾选 **风格融合** 后才展开 **角色／主体画风** 与 **场景／环境画风**，两个作用域各自独立。升级会自动识别 v3 中已选场景画风的存档，保留融合状态。
- **弹窗选择**：通过横向分类标签二级导航和编号搜索筛选，**每个分类一次显示全部匹配素材、没有“加载更多”**；图片保持完整缩略图/大图预览，先暂选再点「确认选用并返回」，取消不改变当前选择。
- **素材画廊**：单独的全屏浏览入口，可按类别和编号搜索、切换卡片密度、放大查看原图。**只浏览，不从画廊选用**。
- **移除原版 HTML 入口**：此前 `原版画廊与提示词拼装器` 一直 404，因此删除了整个 iframe 入口及 `/api/handraw-style.legacy` 接口。DSH 内的原生拼接器继续读取和遵循原 Skill 模板。
- **两个执行按钮**：「生成完整提示词」或「直接生成图片」；两者旁边都可使用 **AI 辅助设计** checkbox。
- **图片下方**：复制图片到剪贴板（浏览器支持时）、保存 PNG、显示实际 DSH Host 本地绝对路径与复制路径按钮。
- **比例**：`3:4`（小红书）、`2:3`（竖图）、`9:16`、`1:1`、`4:3`（文章）、`3:2`（摄影）、`16:9`（视频）、`21:9`、`2.35:1`（宽封面）、`5:2`（X 文章）以及自定义如 `7:10`。原始比例写进提示词；图像 API 的像素尺寸映射到允许的 `1024x1024`、`1024x1536`、`1536x1024`，**不假称实际像素会严格符合自定义比例**。

## AI 辅助设计的执行逻辑

默认 **不勾选**，不会调用 DeepSeek：

```text
用户输入 + 用户选择 → Skill 确定性提示词拼接 → 显示提示词／发送图像 API
```

勾选 **AI 辅助设计（使用 DSH 默认模型）**：

```text
主题 + 已选择参数 → Skill 初步拼接 → DSH 默认模型返回限定参数 JSON（一次调用）
  → 严格校验参数 ID/枚举 → Skill 原版规则重新拼接 → 显示完整提示词／发送图像 API
```

**重要：AI 不负责写提示词正文。** 它仅在仓库原有的 **画风、图型、主题色、影调** 素材清单中推荐有效编号，以及本拼装器中已有的 **画幅预设、纯图/图文模式、留白、SC-021 类型**等固定选项。不能生成补充说明、画面创意、受众文案、场景作文、prompt 正文，也不能改写主题或覆盖用户手动选择。启用风格融合时才允许分别选角色风格和场景风格。模型输出非法 ID、不可用枚举或超范围字段时会**直接报错**，绝不当作最终提示词。没有 DSH 默认模型时同样会明确报错。

为保留已有成果，旧版存档仍可读取；新版本将已有的非默认选项视为用户手动设置，防止 AI 覆盖自定义比例。旧版已生成的 AI 文字不自动改写，重新点击生成即可按新的限定规则执行。

**布局修复（v0.5.0）**：使用插件主内容区的 CSS 容器查询，而不是浏览器总宽度做响应判断。中等宽度改为“作品导航＋编辑区／结果区纵向排列”，窄宽度垂直排列。作品卡片、状态文字、长主题使用可收缩宽度与省略号，避免覆盖右侧表单。已在 1440、1017、850、710、390px 及嵌入宽度 800px 的浏览器环境测试。

## 安装

```sh
# Linux / macOS: 替换绝对路径
dsh plugin --profile web add "link:/absolute/path/handraw-style/plugins/dsh-handraw-style"
dsh web
```

Windows：

```powershell
dsh plugin --profile web add "link:C:\\work\\handraw-style\\plugins\\dsh-handraw-style"
dsh web
```

覆盖原目录后重启 DSH Web。升级时不改已有的 IndexedDB/localStorage 标识以尝试保留历史创作内容。代码不能单独复制到仓库外，因为素材路径依赖 `../../skills/...` 和 `../../images/`。

## 图片接口与保存路径

只有「直接生成图片」需要在插件内配置 **GPT Image 兼容 API** 的 Base URL、Key、模型（默认为 `gpt-image-2`）。无参考图调用 `images/generations`，带上传图或风格参考图调用 `images/edits`，要求返回 `b64_json`。

每张成功生成的 PNG 实际写入：

```text
$DSH_HOME/handraw-style/generated/handraw-<uuid>.png
# 未设置 DSH_HOME 时为：~/.dsh/handraw-style/generated/handraw-<uuid>.png
```

接口响应返回绝对路径并展示在图片下方。**这是 DSH Host 所在机器的路径，不是浏览器下载的保存位置**；如果 DSH 在远程服务器运行，路径也在服务器上。图片同时在当前浏览器 IndexedDB 存一份，以支持切出面板后回显。浏览器下载按钮会触发本地保存，插件无法获知浏览器实际下载目录。图片复制依赖安全上下文与浏览器 Clipboard API，无法使用时请用「保存 PNG」。

## 状态和边界

模块级快照 + localStorage（文本）+ IndexedDB（含图片），对 DSH `main` 面板切换时的 React 卸载做恢复；正在执行的请求不绑定组件卸载。关闭整个 DSH Host 或刷新浏览器时，正在执行的任务仍可能中断。跨不同浏览器、origin、设备不会自动同步。

本次还完成了浏览器交互回归，覆盖创作台、画风/图型/主题色/影调四种浏览画廊、默认四个素材弹窗（开启融合后五个弹窗）、完整预览、接口设置、提示词、AI 辅助、直接生图、图片复制/保存/路径显示、移动端与切换面板恢复。细项见 [`tests/QA-REPORT.md`](tests/QA-REPORT.md)。

可在具备 Python Playwright、Chromium 与本地 React UMD 测试依赖的环境中运行 `python tests/browser-e2e.py`。脚本在**隔离临时目录**中生成少量测试素材，模拟 DSH Host 模型和 GPT Image 接口，不使用真实 API Key、不修改原 Skill 素材。

**测试边界**：模拟浏览器测试不能代替用户本机实际 DSH、默认 DeepSeek 账号和真实图片接口的最终验收。初次部署建议再用真实配置检查调用和浏览器刷新后的 IndexedDB 恢复。
