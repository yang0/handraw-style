# 手绘风工作台 v0.5.0 · 页面与流程验收报告

日期：2026-11-05

## 本轮修复

1. **DSH 内嵌宽度的响应式布局**：修复旧版多列强制最小宽度造成的越界。改为以插件内容容器为准：大宽度三栏、中宽度导航栏＋编辑区（结果区换行）、窄宽度纵向堆叠。导航项通过 `min-width:0` + `overflow:hidden` + `text-overflow:ellipsis` 限制长主题，textarea 则在自身宽度内换行。
2. **AI 限定参数设计**：勾选 AI 后，先编译现有选择为 Skill 原始提示词，再向 DSH 默认模型请求一次结构化选择结果。可返回的字段仅为 style、style2（已开启融合时）、layout、color、tone、mode、ratio、whitespace、layoutVariant；编号必须存在于实际主仓库素材目录，枚举必须在固定预设内。拒绝自由文本、AI 输出的提示词正文、未经登记的创意补充字段及伪造素材编号。
3. **最终提示词由本地 Skill 模板产生**：模型只负责补齐缺失配置，后续由 `compilePrompt` 按原仓库的画风特征、图型 Markdown、颜色/影调模板执行拼接；**不做第二轮 DeepSeek 润色调用**。
4. **锁定手动选择**：用户手动选择的风格、图型、颜色、影调、画幅、模式、留白及 SC-021 类型不会被模型覆盖；旧存档的非默认比例、模式和素材值自动标记为锁定。没有开启融合时只使用一个画风，场景风格不参与拼接。
